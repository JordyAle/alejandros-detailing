ALEJANDRO'S DETAILING — INSTRUCCIONES

1. Abre esta carpeta en Visual Studio Code.
2. Haz clic derecho sobre index.html.
3. Selecciona "Open with Live Server".
4. La página se abrirá en tu navegador.

ARCHIVOS IMPORTANTES

- index.html: contenido, botones y enlaces.
- styles.css: colores, diseño y versión para celular.
- script.js: menú, galería ampliada y año automático.
- img/: imágenes utilizadas en la página.

FUNCIONES INCLUIDAS

- Paquetes organizados por servicio y tipo de vehículo.
- Cada paquete abre WhatsApp con la solicitud ya escrita.
- Cambio completo entre español e inglés.
- Instagram y TikTok visibles desde el encabezado.
- Servicio móvil a domicilio disponible 24/7.
- Cobertura: Orange County, Los Angeles y zonas cercanas.
- Enlace de ubicación mediante Apple Maps.

PUBLICAR EN GITHUB PAGES

1. Crea un repositorio llamado alejandros-detailing.
2. Sube todos los archivos y la carpeta img.
3. En el repositorio abre Settings > Pages.
4. En Source selecciona Deploy from a branch.
5. Elige la rama main y la carpeta /(root).
6. Guarda y espera a que GitHub muestre tu enlace público.
